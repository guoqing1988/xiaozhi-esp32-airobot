🎵 上传歌曲到 TF 卡

选好文件会自动检测参数：单声道 + ≤24kHz + ≤128kbps 的歌直接上传， 其余（wav/m4a/flac 等非 MP3）自动转码为 24000Hz 单声道 96kbps（避免设备端解码卡顿、唤醒失灵）；歌词自动转为 UTF-8。
转码组件按需从 CDN 加载（首次需联网，之后走浏览器缓存；无网时仍可上传本来合格的文件）。
